# Marketing & Content Rules — Viatours Voyage

## Positioning

Viatours Voyage should communicate travel expertise, ease, trust, discovery, and confidence without sounding exaggerated or generic.

## Messaging hierarchy

Use this order when appropriate:

1. Outcome or destination desire.
2. Specific supporting value.
3. Proof/detail.
4. Clear next action.

## Copy principles

- Write for travelers, not for internal teams.
- Prefer concrete benefits over vague adjectives.
- Keep headings scannable.
- Avoid repetitive “best”, “amazing”, “world-class”, and similar claims unless supported.
- Use consistent terminology for tours, destinations, bookings, travelers, and activities.
- Do not invent prices, reviews, statistics, awards, availability, or guarantees.

## Card copy

A good tour card should make the destination/product understandable at a glance:

```text
Image
Location/category
Tour title
Short useful metadata
Rating/review context
Price or starting price
Primary action
```

## CTA language

Use action + outcome where possible:

- Explore tours
- View destination
- See tour details
- Start planning
- Check availability

Avoid vague CTA labels such as “Click here” when a more descriptive action is available.

## Consistency

Marketing copy must support the same visual hierarchy defined in `DESIGN_SYSTEM.md` and the same conversion principles defined in `CRO.md`.
